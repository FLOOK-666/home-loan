# ผ่อนบ้าน — PWA ติดตามการผ่อน 3 สัญญา (กรุงไทย)

เว็บแอปที่ติดตั้งบนมือถือได้ ข้อมูลเก็บใน Google Sheets ใช้ร่วมกัน 2 คน (ฟลุ๊ค และ พัช) มีอีเมลเตือนก่อนวันจ่าย 1 วัน

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `styles.css`, `app.js` | หน้าแอป 5 แท็บ ได้แก่ ภาพรวม / บันทึก / ตารางงวด / จำลองโปะ / ตั้งค่า |
| `engine.js` | สูตรคำนวณแบบเดียวกับธนาคาร: ดอกเบี้ยรายวัน ÷ 365, อัตราเปลี่ยนตามวันที่ |
| `defaults.js` | ค่าเริ่มต้นจาก `home_loan_payment_schedule.xlsx` |
| `bank-schedule.js` | ตารางผ่อนธนาคาร 3 สัญญา สร้างจาก xlsx ด้วย `tools/extract_bank_schedule.py` |
| `apps-script/Code.gs` | backend สำหรับวางใน Google Apps Script |
| `manifest.webmanifest`, `sw.js`, `icons/` | ส่วนของ PWA (ติดตั้งได้ ใช้ออฟไลน์ได้) |

ลองใช้ในเครื่องก่อนได้เลย โดยยังไม่ต้องตั้งค่าอะไร ถ้ายังไม่ได้เชื่อม Sheets แอปจะเก็บข้อมูลไว้ในเครื่อง ("โหมดเครื่องนี้") และพอเชื่อมต่อแล้ว แอปจะถามว่าจะอัปโหลดข้อมูลที่บันทึกไว้ขึ้นชีตไหม

## ส่วนที่ 1: ตั้งค่า Google Sheets + Apps Script (ทำครั้งเดียว ใช้บัญชีของฟลุ๊ค)

### 1. สร้างชีต
1. เปิด <https://sheets.new> แล้วตั้งชื่อ เช่น `ผ่อนบ้าน-data`
2. ไม่ต้องสร้างแท็บเอง เพราะสคริปต์จะสร้างแท็บ `Payments` และ `Settings` ให้เองตอนใช้งานครั้งแรก

### 2. วางโค้ด Apps Script
1. ในชีต ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ให้หมด แล้ววางเนื้อหาทั้งหมดจาก [`apps-script/Code.gs`](apps-script/Code.gs)
3. กด 💾 บันทึก แล้วตั้งชื่อโปรเจกต์ เช่น `ผ่อนบ้าน-api`

### 3. ตั้งเขตเวลาและ PIN
1. คลิก ⚙️ **Project Settings** ทางซ้าย
2. ตั้ง **Time zone** เป็น `(GMT+07:00) Bangkok`
3. เลื่อนลงไปที่ **Script Properties** แล้วกด **Add script property**
   - Property: `PIN`
   - Value: รหัสที่จะใช้ร่วมกัน เช่น `482915` (ใช้ตัวเลขหรือตัวอักษรก็ได้ ยิ่งยาวยิ่งดี)
4. กด **Save script properties**

> PIN คือสิ่งเดียวที่กันคนนอกไม่ให้อ่านหรือแก้ข้อมูลได้ เพราะ URL ของ Web App เรียกได้จากทุกที่ อย่าใช้ PIN เดียวกับบัตร ATM

### 4. Deploy เป็น Web App
1. กดปุ่มสีน้ำเงิน **Deploy → New deployment**
2. คลิก ⚙️ ข้าง "Select type" แล้วเลือก **Web app**
3. ตั้งค่าดังนี้
   - Description: `v1`
   - **Execute as: Me** (อีเมลของฟลุ๊ค)
   - **Who has access: Anyone** (ต้องเป็น Anyone แอปถึงจะเรียกได้ ส่วนการกันคนนอกใช้ PIN)
4. กด **Deploy** แล้วกด **Authorize access** และเลือกบัญชี
   - ถ้าเจอหน้า "Google hasn't verified this app" ให้กด **Advanced → Go to ผ่อนบ้าน-api (unsafe)** แล้วกด **Allow** (ขึ้นแบบนี้เพราะเป็นสคริปต์ของเราเอง ไม่ได้ส่งให้ Google ตรวจ)
5. คัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec` เก็บไว้

ทดสอบ: เปิด URL นั้นในเบราว์เซอร์แล้วต่อท้ายด้วย `?pin=รหัสของคุณ` ต้องเห็น `{"ok":true,"payments":[],"settings":null}`

### 5. เปิดอีเมลแจ้งเตือนรายวัน
1. กลับไปหน้า Editor (ไอคอน `< >`)
2. เลือกฟังก์ชัน **`installTrigger`** จาก dropdown ข้างปุ่ม ▶ Run แล้วกด **Run**
3. อนุญาตสิทธิ์เพิ่ม (ส่งอีเมล / ทำงานตามเวลา)
4. ตรวจที่ ⏰ **Triggers** ทางซ้าย ต้องเห็น `dailyReminder` ทำงานทุกวัน ช่วง 8:00–9:00 น.

การทำงาน: ทุกเช้า สคริปต์จะเช็กว่าพรุ่งนี้มีงวดครบกำหนดไหม ถ้ามีและยอดที่บันทึกยังไม่ครบ จะส่งอีเมลถึงทั้ง 2 คน บอกยอดแยกตามสัญญาและแยกตามคนจ่าย

### 6. เชื่อมแอปกับชีต (ทำในมือถือทั้ง 2 เครื่อง)
1. เปิดแอป แล้วไปที่แท็บ **ตั้งค่า → เชื่อมต่อ Google Sheets**
2. วาง URL `/exec` ใส่ PIN แล้วกด **เชื่อมต่อ**
3. (ทำแค่ครั้งแรก) ในหัวข้อ **แจ้งเตือนทางอีเมล** ใส่อีเมลของทั้ง 2 คนคั่นด้วย `,` ใส่ลิงก์แอป แล้วกด **บันทึก**
4. กด **ส่งอีเมลทดสอบ** แล้วเช็กกล่องจดหมาย (ถ้าไม่เจอ ให้ดูใน Spam)

### เมื่อแก้ `Code.gs` ภายหลัง
**Deploy → Manage deployments →** ✏️ → Version: **New version → Deploy** ทำแบบนี้แล้ว URL เดิมยังใช้ได้ ไม่ต้องกรอกใหม่ในแอป

## ส่วนที่ 2: Deploy ฟรีบน GitHub Pages

> ⚠️ ถ้าใช้ GitHub ฟรี repo ต้องเป็น **public** คนอื่นจะเห็นโค้ดและยอดเงินกู้ในค่าเริ่มต้น (ไม่มีชื่อคน) ส่วนรายการจ่ายจริงอยู่ใน Google Sheets ซึ่งมี PIN กันไว้ ไฟล์ `.xlsx` มีชื่อ-นามสกุลจริง และถูกกันไว้ใน `.gitignore` แล้ว

1. สร้าง repo ใหม่ที่ <https://github.com/new> เช่นชื่อ `home-loan` ตั้งเป็น **Public** และไม่ต้องติ๊กสร้าง README
2. ในเครื่อง รันคำสั่งในโฟลเดอร์ `Home_Loan`:
   ```bash
   git init -b main
   git add .
   git status            # เช็กว่าไม่มีไฟล์ .xlsx ในรายการ
   git commit -m "home loan tracker"
   git remote add origin https://github.com/<username>/home-loan.git
   git push -u origin main
   ```
3. ใน repo ไปที่ **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main**, โฟลเดอร์ **/ (root)** แล้วกด **Save**
4. รอประมาณ 1–2 นาที จะได้ลิงก์ `https://<username>.github.io/home-loan/`

### ติดตั้งบนมือถือ
- **Android (Chrome):** เปิดลิงก์ แล้วกดเมนู ⋮ → **ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก**
- **iPhone (Safari):** เปิดลิงก์ แล้วกดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

### อัปเดตแอป
แก้ไฟล์แล้ว `git commit` และ `git push` จากนั้นแอปบนมือถือจะโหลดเวอร์ชันใหม่เองในครั้งถัดไปที่เปิดตอนออนไลน์

## ข้อมูลในแอปมาจากไหน

- **ตารางธนาคาร (ใช้เป็นเส้น "สัญญาเดิม" และค่างวดขั้นต่ำ):** ฝังมาจาก xlsx ถ้าไฟล์เปลี่ยน ให้รัน `python tools/extract_bank_schedule.py`
- **แผน (ค่างวดที่ตั้งใจจ่าย แยกตามคน):** มาจากแท็บ "แผนรวมผ่อนชำระ" แก้ได้ในหน้าตั้งค่า
  - บ้าน: 10,200 (งวด 1–12) → 14,760.20 (งวด 13–36) → ฟลุ๊ค 16,980 + พัช 10,000 (งวด 37 ขึ้นไป)
  - ประกัน MRTA: 2,811.25 (งวด 1–36 และปิดยอดที่งวด 36)
  - ตกแต่ง: 9,409.09 (งวด 1–36 และปิดยอดที่งวด 36)
- **ยอดคงเหลือจริง:** ใช้ "ยอดคงเหลือตามธนาคาร" ที่บันทึกไว้ในแต่ละรายการ ถ้าไม่ได้ใส่ แอปจะคำนวณเองจากยอดที่จ่าย
- **แผนใหม่และเครื่องจำลองโปะ:** คำนวณจากยอดจริงล่าสุดด้วยสูตรเดียวกับธนาคาร และถือว่าโปะแล้วค่างวดเท่าเดิม แต่จบเร็วขึ้น

สูตรใน `engine.js` ตรวจเทียบกับตารางธนาคารแล้ว: บ้านต่างกันไม่เกิน 0.08 บาทตลอด 392 งวด และ MRTA ต่างกันไม่เกิน 0.05 บาท

### ข้อสังเกตจากไฟล์ xlsx
- แท็บประกัน งวด 25–224 ไม่มีตัวเลข แอปคำนวณเติมให้ (มีหมายเหตุกำกับในตาราง)
- แท็บตกแต่ง งวด 125–299 ใช้อัตราดอกเบี้ยไม่สม่ำเสมอ (4.70% → 3.76%) ต่างจากแท็บอื่นที่ใช้ 4.58% แต่ไม่กระทบแผน เพราะตกแต่งปิดที่งวด 36
- แดชบอร์ดใน xlsx เขียนว่า "สัญญาเดิม 40 ปี / เร็วกว่า 25 ปี" แต่ตารางบ้านของธนาคารจบงวด 392 (~32.7 ปี) ตามแผนจึงเร็วขึ้นประมาณ 17.6 ปี
